Keap XML-RPC · March 2027

Keap XML-RPC deprecation starts March 2027: moving to REST v2

Keap's XML-RPC API was first announced as shutting down on December 31, 2026. Keap staff on the developer forum later said that was changed: "Sunset has been changed to deprecation. Deprecation begins March 2027." (Keap developer forum). I could not load Keap's own help article, so treat the exact day as unconfirmed and check it before you plan around it. This is a soft deadline: deprecation means no support, not a shutdown date.

What to move to

The replacement is the REST API v2 at https://api.infusionsoft.com/crm/rest/v2/. Legacy API keys were already retired in 2024-25, so authentication is a personal access token, service account key or OAuth.

Inventory first

Search for infusionsoft.com/crm/xmlrpc, /api/xmlrpc, xmlrpc client calls with ContactService or DataService, and the old Infusionsoft SDKs. The free check flags these and counts the files.
