HubSpot API · March and September 2027

HubSpot v4 goes unsupported in March 2027: who needs to move

This one is a soft deadline, so here is what is and isn't true. HubSpot says: "In March 2027, HubSpot v4 APIs will move to an unsupported state." Unsupported versions "may continue to function for some period of time, but they are not guaranteed to remain stable or available" (HubSpot changelog). The v1 to v3 APIs and legacy apps go unsupported after September 2027, and marketplace apps still using them lose certification (HubSpot changelog). The recommended target is the date-based API version 2026-09.

Who should act now

  • Marketplace app developers. Certification is the real consequence. Plan the migration before September 2027.
  • Everyone else. Nothing stops on a date, but "unsupported" means no fixes. Legacy private apps can no longer be created (since October 26, 2026); use service keys. HubSpot notes that not every legacy replacement path is finalized yet, so start with inventory rather than a rewrite.

Inventory first

Search for api.hubapi.com/crm/v3, /crm/v4, /contacts/v1, hapikey= and the @hubspot/api-client or hubspot-api-client packages. The free check flags these and tells you how many files are involved.
