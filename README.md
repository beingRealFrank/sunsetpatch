# Sunsetpatch

https://beingrealfrank.github.io/sunsetpatch/

Apple sunsets the Apple Ads Campaign Management API (api.searchads.apple.com/api/v5) on January 26, 2027. This is a free check that finds every affected call in a codebase and maps it to the Apple Ads Platform API. It runs in the browser, and there is also a one-file Python CLI (`sunset_scan.py`, standard library only). It also flags Google Custom Search JSON API (Jan 1, 2027), Exchange Online EWS (Apr 1, 2027), HubSpot v1-v4 and Keap XML-RPC.

```
python3 sunset_scan.py path/to/repo --md report.md
```
