Apple Ads API · January 26, 2027

Your Apple Ads integration stops working on January 26.

Apple is sunsetting the Campaign Management API, which is every call to api.searchads.apple.com/api/v5 (and any leftover v4). The replacement, the Apple Ads Platform API, uses a new host, a new context header, new resource paths and a new report format. Reporting pipelines, bid scripts, ETL connectors and dashboards all need changing.

From Apple's changelog: "The Apple Ads Campaign Management API is deprecated and will be sunset on January 26, 2027. Use the Apple Ads Platform API instead." (source)

FAQ

Will Apple extend the date?

Apple hasn't said it will. Its changelog gives January 26, 2027. The Platform API has been live since August 2026, so you can test against it today.

We use a connector (Airbyte, a Singer tap, an MMP). Are we affected?

Only if the connector still calls the old API. Run the check on its source, or ask its vendor. For self-hosted or forked connectors, the Connector package covers the update.

Do you need our Apple Ads credentials?

No. We work from the code and Apple's documented payloads. You run the live test. If you'd like us to run it, a read-only API user on a test account is enough, and we remove it afterwards.

What if the check finds nothing?

Then you're probably fine. The check matches literal hosts, paths and library names, so code that builds URLs from settings it can't see may slip through. The CLI scans config files too.
