Google Custom Search JSON API · January 1, 2027

Google Custom Search JSON API replacement: what to do before January 1

Google's own overview page says: "Existing Custom Search JSON API customers have until January 1, 2027 to transition to an alternative solution." (Google). The same page describes the end as a "service discontinuation" on that date. Google's suggested replacement is Vertex AI Search, which supports up to 50 domains.

Do you use it?

Search your code for googleapis.com/customsearch/v1, a cx= parameter, GOOGLE_CSE_ID or GOOGLE_API_KEY next to a search call, or client libraries named googleapiclient ... customsearch, google-api-python-client with cse(), or @googleapis/customsearch. WordPress and Joomla plugins, site-search widgets, SEO and rank-tracking tools, research scrapers and LLM "web search" tools commonly depend on it. The free check finds these.

Migration checklist

  1. Inventory. List every place that builds a Custom Search request, and what fields of the response you read (items[].title, link, snippet, pagemap, searchInformation.totalResults).
  2. Pick a target. Vertex AI Search if you search your own sites (it needs a Google Cloud project and a data store); another web search API if you search the open web. Check pricing and quotas for each before you commit.
  3. Put an adapter in front. One function that takes a query and returns the same result shape your code already reads. The rest of your application then never learns the provider changed.
  4. Handle limits. Custom Search paged with start and num; your new provider will page differently.
  5. Ship before January 1. A discontinued API usually fails abruptly rather than degrading, so test the fallback path too.
