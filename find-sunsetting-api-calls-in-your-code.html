How to find every sunsetting API call in your code

Before you plan any migration, list every place your code talks to the old API. Run these from the repository root. They are plain text searches, so expect a few false positives in docs and tests. Check the dates on the shutdown calendar.

Apple Ads Campaign Management API v5 (hard, January 26, 2027)

grep -rnE "api\.searchads\.apple\.com|/api/v5|X-AP-Context|orgId" .

Google Custom Search JSON API (hard, January 1, 2027)

grep -rnE "googleapis\.com/customsearch|customsearch/v1|cx=|build\(.customsearch." .

Exchange Online EWS (hard, April 1, 2027)

grep -rniE "Exchange\.asmx|exchangelib|Microsoft\.Exchange\.WebServices|EWS/|ews\.office365|full_access_as_app" .

HubSpot (soft)

grep -rnE "api\.hubapi\.com/(crm/v3|crm/v4|contacts/v1)|hapikey=|@hubspot/api-client|hubspot-api-client" .

Keap XML-RPC (soft)

grep -rniE "infusionsoft\.com/(crm/)?xmlrpc|api/xmlrpc|ContactService|DataService" .

Also search your environment files, CI secrets names and cron jobs: the old calls often live in scripts nobody has opened for years. The free check does all of the above in your browser, lists each call with its file and line, and nothing is uploaded.
